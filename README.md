# Munchies! 🐾

A landing page for a made-up dog food brand, created as practice to improve my HTML and CSS Flexbox skills.

> Munchies! is a fictional brand. This website is only an exercise and is not meant to sell anything.

## About the project

I originally wanted to recreate a design I found on Pinterest, like i did previously with the Drinko design. Once i started working on it, i sadly realized it had been fully generated with AI. So there is no original author i can credit.
I decided to keep going anyway and did my best to recreate it on my own: i took inspiration from the original design, and sketched on paper all the changes. 
The brand name, texts and graphics are my ideas.

## Sections

- Header with navigation buttons
- Hero with title and illustrations
- Info section with brand's formula specifics
- Product section with all the product lines
- Newsletter call-to-action with an email form
